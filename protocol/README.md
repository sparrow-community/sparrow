Sparrow protocols are defined with Protocol Buffers and generated by Buf.

- `event.v1` — append-only execution ledger (`Event` / `Element`)
- `job.v1` — pull-worker RPC (`JobService`); implemented by the `gateway` module
- `engine.v1` — process-client RPC (`EngineService`: Deploy / CreateInstance / Complete / PublishMessage / query)

```shell
cd proto && ./build.sh
```

Generated Go code is written to `gen/go`. The gRPC plugin is pinned in `buf.gen.yaml`.
